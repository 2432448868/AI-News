只使用免费公开 API 与 RSS，不调用付费 AI 或翻译服务。标题与简介保留原文，所有内容都能追溯来源。

如何理解这里的“热门”？

GitHub 按近期活跃仓库的累计 stars 排序；Hugging Face 按来源热门榜发现。模型更新不等于正式发布，项目上榜不构成安全背书。

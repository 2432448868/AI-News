# AI News 需求文档

## 1. 项目定位
- 产品名称：Signal · AI 日报。
- 面向开发者和 AI 爱好者，聚合值得关注的新闻、项目、模型和实践。
- 用户已授权自主完成需求、选型、评审、编码与自验收；不代替用户提交或发布仓库。
- 版本：v1.0；日期：2026-10-03（Asia/Shanghai）。

## 2. 硬约束与默认决策
| 项目 | 要求 |
|---|---|
| 托管 | GitHub Pages；公开仓库；无常驻后端、无数据库 |
| 采集 | 仅免费公开 API/RSS，无付费模型、爬虫代理、翻译或搜索服务 |
| 更新 | 每日自动尝试更新，失败保留上次数据；提供手动触发入口 |
| 用户端 | 无需登录；中文界面；外文内容保留原文，不伪造中文摘要 |
| 时区 | 统一按北京时间展示，明确数据更新时间 |
| 视觉 | 简约、大留白、圆角、克制色彩、精细排版；借鉴苹果，不复制品牌素材 |
| 主题 | 浅色/深色切换，首次跟随系统，记住用户选择 |

## 3. 内容范围
| 分类 | 内容 | 来源/口径 |
|---|---|---|
| AI 动态 | 官方公告、行业进展 | 官方 AI RSS；不声称覆盖全网 |
| 开源项目 | 活跃 AI 仓库 | GitHub 搜索 API；累计 stars，不冒充今日增长 |
| Skills | Agent Skills 仓库、技能集合 | GitHub topic/关键词；不自动安装或执行 |
| 模型 | 模型发现与动态 | Hugging Face models；创建、更新与正式发布严格区分 |
| 实用技巧 | 官方教程、实践指南 | RSS 标题与分类规则；可与开发实践关联 |
| 趣味应用 | 可体验的 AI demos | Hugging Face Spaces + GitHub Gradio demos；仅跳转，不运行远端代码 |
| 开发实践 | AI 编码、Agent 工程实践 | GitHub AI 博客及教程 |

## 4. 页面与交互
- 首页：日期、采集状态、品牌介绍、头条精选、开源排行、分类信息流。
- 卡片：分类、标题、短摘要/描述、来源、原始日期、收藏、原文链接。
- 标题与摘要来自源站；摘要做纯文本清理与长度截断，不生成未经核实的结论。
- 筛选：分类、关键词、时间范围；排序：最新动态/热度参考。
- 收藏：仅存浏览器，支持筛选查看；不承诺跨设备同步。
- 历史：保留最近 30 天文章与最近成功采集的项目快照；不做永久历史库。
- 来源面板：逐源展示本轮成功/失败、最近成功时间、数据量和错误信息。
- 状态：加载、空结果、无收藏、请求失败、部分来源失败、超过 36 小时未更新。
- 分页：前端分批展示，每次 12 条；过滤后重置分页。
- 支持桌面与手机，键盘操作、可见焦点、减少动态效果偏好。

## 5. 数据规则
- 以规范化原文 URL 去重；同一条内容可属于多个分类。
- 分开存储 publishedAt、updatedAt、collectedAt，不能把采集时间伪装成发布时间。
- 热度仅作发现参考：来源内部排名映射为分数；不同平台不宣称可比的真实热度。
- 过滤明显无关、归档和 fork 仓库；Skills 仅指 AI Agent 技能，不指泛编程技能。
- 展示来源署名与原文链接；不转载全文、不下载源站图片。
- 请求超时与有限重试；单源失败不阻断其他源；全部源失败不覆盖线上页面。
- 不隐藏缺失：某类没有可用数据时显示真实空状态，不灌入模拟新闻。

## 6. 免费与运维边界
- 默认公共仓库 + GitHub 标准托管 runner + Pages，无付费依赖。
- GITHUB_TOKEN 为工作流自动提供的免费鉴权，不需要购买 GitHub API。
- API 限流、平台额度/政策仍适用；不配置付费 runner、付费 API 或自购域名。
- GitHub 定时任务可能延迟/丢弃；公开仓库长期无活动可能自动停用调度。
- 因此“每日更新”是每天自动执行计划，不承诺免费平台提供 24 小时强 SLA。
- 管理员需在仓库中启用 Pages/Actions，并关注失败通知和长期停用提示。

## 7. 非目标
- 登录、评论、邮件推送、付费订阅、全文翻译、个性化推荐、实时抓取、管理后台。
- 自动安装 Skills、自动执行开源仓库代码、对项目安全性背书。

## 8. 验收标准
| 编号 | 验收项 |
|---|---|
| A01 | 构建、类型检查、自动化测试通过；生产目录可静态访问 |
| A02 | 真正从免费来源抓取数据，显示可追溯原文与真实时间 |
| A03 | 分类、搜索、排序、时间过滤、分页、收藏可组合使用 |
| A04 | 深浅主题切换与刷新后持久化；360px 移动端无横向溢出 |
| A05 | 恶意 HTML 不执行、不允许 javascript: 原文链接 |
| A06 | 单源失败有提示、全失败不覆盖数据、重试有次数上限 |
| A07 | GitHub 项目子路径构建可访问，无根路径资源错误 |
| A08 | 定时更新、手动更新、Pages 部署工作流完备 |
| A09 | 记录实际验证结果，不能把尚未远程部署写成上线完成 |

> 故障保留例外：失败来源沿用上次成功快照，文章可能超过 30 天；保留原始日期并标记来源失败，不伪装成新内容。
